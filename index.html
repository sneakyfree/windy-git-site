Never heard of Git? Here's the idea

Think of it as a time machine for anything you build.

Programmers have used this kind of tool for twenty years, because losing work hurts and mistakes happen. The idea is simple enough for anyone, and it matters more now that AI helpers make changes for us.

Undo, forever

Not just the last step. Any moment in a project's life, from day one, is a save point you can return to.

A family album

See every version side by side, who changed what, and when. Like a photo album of your work, with captions.

Try ideas safely

Copy a project into a side version, experiment freely, and only bring the changes back when they're good. The original never breaks.

A safe deposit box

Your work lives off your computer, copied and backed up. A broken laptop is an inconvenience, not a disaster.

Why it matters more now

When an AI helper changes your work for you, you deserve to see exactly what it changed, and to undo it in one step.

That is the whole promise of save points. Windy Git keeps a clear record of every change: what changed, who or what changed it, and when. If a change was a mistake, you go back. Nothing is overwritten and nothing is quietly lost.

This is how the Windy team works on Windy today: people and AI helpers both make changes, and every one of them is a reviewable, reversible save point.

What Windy Git does today

Only what is live. Nothing promised that isn't.

Every item marked Live is running in production right now. Things we haven't built yet are marked Not yet, further down.

Live

One Windy login

Sign in with the same Windy account you use everywhere else. There's no separate password to forget, and no password form to attack.

Live

Automatic checks on every change

Each change runs the project's tests on our own machines, and the result shows up as a green check or a red cross where the team works.

Live

Secrets stay secret

A guard stops passwords and keys from slipping into code. When it catches one it shows only a short fingerprint, never the secret itself.

Live

Encrypted nightly backups

Every project, plus the full history of discussions and reviews, is backed up encrypted every night. And we've proven a restore from that backup on a different machine.

Live

Always in step with GitHub

Windy's projects are mirrored from GitHub within minutes, so there are always two independent copies.

Live

Checks run walled off

Test jobs run in isolated containers that can reach the internet but never our internal network. A bad change can't wander off and touch anything else.

For developers

Private-repo CI that reports back to GitHub.

Windy Git runs on open-source Gitea, behind Windy single sign-on. Today it's the continuous-integration layer for every private Windy platform repo. You keep pushing to GitHub as usual; the verdicts come back to your pull request as commit statuses.

  • GitHub → Windy Git sync every 5 minutes; same-repo PRs get mirror PRs automatically
  • Gitea Actions, GitHub-Actions-compatible workflow syntax, on self-hosted runners
  • Statuses posted as windy-git/<workflow>/<job> on PR heads and the default branch
  • Guards on every PR: secret-guard (blocks), compute-guard, ci-hygiene
  • Fork PRs never run: untrusted code never reaches the runners
# push to GitHub as always $ git push origin my-feature # ...a few minutes later, on the PR: ✓ windy-git/ci/test ✓ windy-git/ci/lint ✓ windy-git/secret-guard OK: no secret-shaped strings added ✓ windy-git/compute-guard OK: Windy Mind is the only door

Workflows use runs-on: [self-hosted, linux, x64]. Job containers have no Docker daemon by design, so image builds belong in the deploy step, not in CI.

Questions

Fair questions, straight answers.

Is Windy Git the same as GitHub?

No. GitHub is a separate company's service. Windy Git is the Windy family's own home for code, built on the open-source Gitea project and run on our own machines. Today it mirrors Windy's GitHub projects and runs their automatic checks.

I'm not a programmer. Is this for me?

Not yet, honestly. The idea (save points, history, safe experiments, backups) is useful for anyone, but today Windy Git is the Windy team's workshop. When it opens to members, we'll explain it on this page in plain language first.

Can I sign up?

Not yet. Sign-in works only for people who already have Windy Git access, using their Windy account. New sign-ups are closed until member access opens.

Who can see a private project?

Only the people given access to it. Private projects are not listed or visible to anyone else.

What happens if a password ends up in code by accident?

The secret guard flags it on the pull request before it's merged, showing only a fingerprint of the secret, never the secret. The team then removes it and changes the password.

What does "Git" mean?

Git is the free, open-source tool programmers use to keep the history of their work. Windy Git is a place to keep that history safely, together.
